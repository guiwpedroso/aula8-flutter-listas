# PDM Aula 8 — Listas Flutter

Atividade da Aula 8 de **Programação para Dispositivos Móveis I**, desenvolvida em Flutter.

## 📱 Sobre

Aplicação de catálogo de produtos utilizando:

* `ListView.builder`
* `Dismissible`
* `setState()`
* Navegação entre telas
* Arquitetura modular

## 📂 Estrutura

```text
lib/
├── models/
├── widgets/
├── screens/
└── main.dart
```
